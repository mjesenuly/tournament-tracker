# Design system

English university football UI with neutral #f5f6f8 page background, white cards, dark blue-gray text #25334a, restrained blue #315c91 actions and muted red #b34d5c score/error accents. System sans-serif typography avoids external font dependency. Hierarchy uses a compact brand header, clear tournament titles, count cards, then standings, fixtures, private application management and teams.

Responsive grids collapse on mobile; tables scroll inside their panel. Buttons expose meaningful actions, labels bind form controls, loading has role=status and primary errors role=alert. Private identifiers appear only in authenticated permitted application/proposal panels. Explicit demo banner names fictional accounts. The app has no generated photography or visual decoration obscuring tournament information.
