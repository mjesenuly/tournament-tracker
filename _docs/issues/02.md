# TT-02 — Google authentication and organizer authorization

Status: Open / BLOCKED: live Google sign-in is not configured and verified
GitHub issue: https://github.com/mjesenuly/tournament-tracker/issues/2
Product source: ../plan.md

## Goal

Authenticate captains and authorize only preassigned organizers managing their own tournaments.

## Acceptance criteria

- [ ] Real Google OAuth validates provider identity and establishes a server session; failures are handled.
- [ ] Organizer role comes from a configured preassigned email allowlist; users cannot assign their own role.
- [ ] Only owner organizers mutate their tournaments; captain and anonymous unauthorized requests fail server-side.
- [ ] Session expiry/sign-out work and sensitive credentials never appear in client bundles.
- [ ] Student IDs and captain contacts are absent from anonymous/public server projections.

## Out of scope

Password login, additional providers and self-appointed organizers.

## Constraints

Validate OAuth state and provider tokens, use secure production cookie settings and CSRF protection as appropriate. Demo identity must be explicitly separate from real OAuth. Depends on 01.

## Handoff and verification

Engineer records actual implementation commit and executed checks. Independent QA records criterion evidence and PASS/FAIL; failures return to engineer. Orchestrator alone closes a real issue after QA PASS. No implementation or publication is claimed by this specification.
