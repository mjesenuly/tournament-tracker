# TT-01 — Foundation and server persistence

Status: Closed: orchestrator confirmed GitHub UI closure before 2026-10-13 13:10 UTC+5
GitHub issue: https://github.com/mjesenuly/tournament-tracker/issues/1
Product source: ../plan.md

## Goal

Run the application with a reproducible TypeScript stack and durable server data.

## Acceptance criteria

- [ ] React/TypeScript/Vite frontend and Node.js/Express backend start with documented commands.
- [ ] SQLite schema and setup persist tournaments, identities, applications, historical memberships, fixtures and goals.
- [ ] Data remains after server restart; invalid writes do not corrupt valid records.
- [ ] Build and relevant foundation tests execute with recorded results.

## Out of scope

Cloud hosting and unrelated infrastructure.

## Constraints

Use SQLite transactions, parameterized SQL, environment configuration and no committed secrets. Dependency: documented architecture.

## Handoff and verification

Engineer records actual implementation commit and executed checks. Independent QA records criterion evidence and PASS/FAIL; failures return to engineer. Orchestrator alone closes a real issue after QA PASS. No implementation or publication is claimed by this specification.
