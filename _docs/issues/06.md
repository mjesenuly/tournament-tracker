# TT-06 — Results, standings and scorers

Status: Independent QA PASS; open awaiting explicit authorization for orchestrator closure
GitHub issue: https://github.com/mjesenuly/tournament-tracker/issues/6
Product source: ../plan.md

## Goal

Calculate correct scores, shared rankings, scorers and completion from editable match results.

## Acceptance criteria

- [ ] Only owner records/edits valid nonnegative integer results and associated goal events.
- [ ] Goal authors are validated against historical match-time roster snapshots; edits work after player replacement.
- [ ] Own goals count toward opponent score and never increase scorer totals; events reconcile with score.
- [ ] Finished results generate played/wins/draws/losses/GF/GA/GD and 3/1/0 points.
- [ ] Sort descending points/GD/GF; exact ties receive shared competition ranks such as 1,1,3 and shared champions.
- [ ] Corrections recompute rather than accumulate statistics; all-finished fixtures mark completion.

## Out of scope

Cards, live commentary and disciplinary forfeits.

## Constraints

Stable identities and historical snapshots are mandatory. Pending matches excluded from standings. Depends on 05.

## Handoff and verification

Engineer records actual implementation commit and executed checks. Independent QA records criterion evidence and PASS/FAIL; failures return to engineer. Orchestrator alone closes a real issue after QA PASS. No implementation or publication is claimed by this specification.
