# TT-03 — Tournament management and public dashboard

Status: Pending
GitHub issue: https://github.com/mjesenuly/tournament-tracker/issues/3
Product source: ../plan.md

## Goal

Allow authorized creation and public discovery of university football tournaments.

## Acceptance criteria

- [ ] An allowlisted organizer creates and edits only their tournaments with validated fields including a required valid calendar start date.
- [ ] Spectators view directory, tournament overview, progress, upcoming fixtures and results without login.
- [ ] English responsive interface uses neutral styling with restrained blue/red accents.
- [ ] Loading, empty, validation and server error states are usable; navigation works.

## Out of scope

Knockout tournaments, esports and payments.

## Constraints

6v6 single round robin only. Server-side ownership required. Depends on 01–02.

## Handoff and verification

Engineer records actual implementation commit and executed checks. Independent QA records criterion evidence and PASS/FAIL; failures return to engineer. Orchestrator alone closes a real issue after QA PASS. No implementation or publication is claimed by this specification.
