# TT-08 — Independent QA and submission verification

Status: Pending
GitHub issue: https://github.com/mjesenuly/tournament-tracker/issues/8
Product source: ../plan.md

## Goal

Provide evidence that approved journeys work and documentation matches actual implementation.

## Acceptance criteria

- [ ] Independent QA verifies public, captain and owner workflows and records PASS/FAIL by criterion.
- [ ] Executed checks cover privacy projections, authorization, persistence restart, round robin, own goals, tied ranks, corrections and replacements.
- [ ] Responsive views, forms, empty/error states and navigation are inspected with actual evidence.
- [ ] Failures are fixed and independently retested before PASS.
- [ ] README documents setup, OAuth/organizer configuration and real limitations; issue/commit references are genuine.
- [ ] Orchestrator closes only actual PASS issues with linked commits and checks real timestamps against deadline.

## Out of scope

Fabricated test reports and claims of deployment without verification.

## Constraints

Real GitHub work must exist before issue URLs/status are recorded. Deadline 2026-10-13 09:20 UTC. Depends on 01–07.

## Handoff and verification

Engineer records actual implementation commit and executed checks. Independent QA records criterion evidence and PASS/FAIL; failures return to engineer. Orchestrator alone closes a real issue after QA PASS. No implementation or publication is claimed by this specification.
